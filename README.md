## Analysis Approach

The analysis was structured at four levels to move from overall campaign effectiveness to specific audience and campaign insights.

### 1. Overall Campaign Performance

First, treatment and control groups were compared across the full dataset.

We calculated:
- Treatment conversion rate
- Control conversion rate
- Absolute difference in conversion rates
- Relative lift
- Statistical significance
- 95% confidence interval

**Question:** Did advertising make a measurable difference overall?

### 2. Campaign-Level Performance

The same analysis was then repeated separately for each campaign.

For each campaign, we calculated:
- Treatment conversion rate
- Control conversion rate
- Absolute difference
- Relative lift
- p-value
- 95% confidence interval

**Question:** Which campaigns performed best?

### 3. Audience-Level Performance

The analysis was then repeated for each audience segment.

For each audience segment, we calculated:
- Treatment conversion rate
- Control conversion rate
- Absolute difference
- Relative lift
- p-value
- 95% confidence interval

**Question:** Which audiences responded best?

### 4. Campaign × Audience Performance

Finally, we analyzed each campaign and audience combination.

For each combination, we calculated:
- Treatment conversion rate
- Control conversion rate
- Absolute difference
- Relative lift
- p-value
- 95% confidence interval
- Treatment and control sample sizes

**Question:** Which specific campaigns worked best for which audiences?

### Analytical Progression

**Overall → Campaign → Audience → Campaign × Audience**

This progression allows the analysis to move from a high-level measure of campaign effectiveness to specific, actionable insights for campaign and audience strategy.
